# Quanto Custa a Viagem?

Página web que calcula o custo de uma viagem de carro em Portugal (combustível, portagens e estacionamento) e quanto paga cada pessoa.

**Problema que resolve:** em viagens com amigos há sempre a conversa de "quanto é que cada um dá para a gasolina?". Aqui fazes as contas num segundo e mandas o resumo para o grupo.

🔗 **Experimenta online:** https://martiinnsss.github.io/custo-viagem/

## Funcionalidades

- **Gasolina, gasóleo, GPL ou elétrico**, cada um com o seu consumo e preço de referência
- Viagem **só de ida ou ida e volta**
- **Portagens** e **estacionamento**
- Divisão por até 9 pessoas
- Custo total, **custo por pessoa** e custo por km
- Botão para **copiar um resumo** pronto a colar no WhatsApp
- Funciona no computador e no telemóvel, sem instalar nada

## Como usar

Abre o ficheiro `index.html` no browser.

## Limitações

- Os preços dos combustíveis que vêm preenchidos são uma referência (médias de novembro de 2026, com base nos dados da DGEG) e mudam todas as semanas; ajusta ao preço que vais pagar
- Não inclui desgaste do carro, seguro nem manutenção

## Tecnologias

HTML · CSS · JavaScript (sem bibliotecas nem frameworks)
